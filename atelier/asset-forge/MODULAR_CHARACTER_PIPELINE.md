# Modular 3D Humanoid Character Pipeline & Recipe (`Meshy AI + VRoid + Mixamo`)

Canonical cross-session recipe for generating, rigging, assembling, and verifying modular 3D humanoid characters in `atlas-world-svc` with **swappable outfits, swappable hair, live anime face expressions, and zero sticky-feet / broken-head defects**.

Also indexed globally in `~/.claude/skills/game-character-3d/references/recipes.md` (§ *Modular 3D Humanoid Character & Swappable Outfit/Hair/Face Pipeline*).

## 1. Modular Slot Architecture (How Outfit, 360° Head, Hair, Ornaments, and Weapons Swap)

Because Image-to-3D generators (`Meshy AI`, `Tripo`) reconstruct a single outer shell from whatever is visible in the 2D image—and carving a VRoid `FaceMesh` into an AI 3D head tears the sideburns and leaves a side seam—**we join the AI 3D Body/Outfit and the Full 360° VRoid Head + Hair at the Neck Collar Socket (`collar_z ≈ 0.764m`)** via [`atelier/asset-forge/scripts/modular_vroid_head.py`](file:///Users/pasitnusso/workspace/repos/atlas-world-svc/.claude/worktrees/F-188-interactive-playtest-sandbox-client-shar/atelier/asset-forge/scripts/modular_vroid_head.py):

| Slot | Node / Material in GLB | Parent Bone / Driver | How to Swap / Customize |
|---|---|---|---|
| **Slot 1: AI 3D Body & Outfit** | `CharacterMesh` (`Material 0 = Body`, `z <= 0.764m`) | Full Humanoid Armature (`Hips`, `Spine*`, `Left/RightUpLeg`, `Left/RightArm`) | Generated by Tripo P1 / Meshy AI; 100% of the AI head above `collar_z` is removed so zero AI head polygons remain |
| **Slot 2: Full 360° VRoid Head + Neck + Elf Ears** | `FaceMesh` (`Face_00_SKIN`, `EyeIris`, `EyeHighlight`, `FaceBrow`, `FaceEyeline`) | `Head` + `Neck` bones + 5 BlendShapes (`eye_blink`, `eye_happy`, `eye_angry`, `eye_sorrow`, `eye_surprised`) | Welds `Victoria_Rubin.vrm` (CC0) `Face.baked` + `Body.baked[Neck + BackSkull]` into ONE watertight 360° head & neck sharing one skin texture; morphs native ears (`--ear-style elf\|human`); scales via `--head-scale` |
| **Slot 3: Modular Wavy Hair + Scalp Cap + Bun** | `HairMesh` (`VRoidHairStrandLuminance` procedural strand texture) | `Head` + `sec_hair_c1_1..4`, `sec_hair_l1_1..2`, `sec_hair_r1_1..2` (120Hz `SecondarySpringPhysics.cs`) | Swappable `.vrm` hair donor (`--vroid-hair`, default `Sendagaya_Shino.vrm` CC0) + `Body.baked[HairBack]` scalp cap + sinusoidal wave (`--hair-wave 1.0`) + `CharacterCustomization.ApplyHairColor()` (`[H]` key) |
| **Slot 4: 3D Crown Ornament & Hairpin** | `CrownOrnamentMesh` (`HairpinGold` metallic material) | `Head` bone (`1.0` rigid weight) | Separate 3D gold ring + tapered hairpin + dangling beads; named without `"hair"` so `CharacterCustomization.IsHairSurface` never tints it white |
| **Slot 5: Weapon Socket & Mixamo Presets** | `WeaponSocket` (`handslot.r`) + `mixamo_<id>_presets.glb` | `prop_weapon_r` -> `handslot.r` + Shared Humanoid Skeleton (`12` Idle + `9` Move clips) | `WeaponSocket.Equip()` (`[E]` key), `CycleIdlePreset()` (`[I]` key) & `CycleLocomotionPreset()` (`[K]` key) |

### Reusable CC0 Base Models Library (`/Users/pasitnusso/asset-studio-private/atlas-3d-plan/vroid_bases/`)
- `Victoria_Rubin.vrm` (CC0 Public Domain) — Default 360° head, neck, and 5-expression eye blendshape donor.
- `Sendagaya_Shino.vrm` (CC0 Public Domain) — Default symmetrical long flowing hair donor (`len = 0.57m`).
- `HairSample_Female.vrm`, `Sakurada_Fumiriya.vrm`, `Vita.vrm`, `Vivi.vrm` (all CC0 Public Domain) — Additional swappable `--vroid-hair` donors.

## 2. Stage 1 — 2D Turnaround Generation in ChatGPT (Mandatory Pre-Meshy Prompt)

Never feed a beauty-pose illustration (crossed legs, touching heels, floor shadows, long hair hiding the shoulders/back, or floor-length skirts bridging the ankles) directly into Meshy AI.

Copy-paste this exact prompt into ChatGPT alongside the concept reference sheet:

```text
Create a clean 3D-modeling orthographic turnaround sheet (Front view, Left Side view, Back view, side-by-side) of the character from the attached reference sheet, prepared for modular 3D game character generation:

1. MODULAR HEAD & HAIR (FOR SWAPPABLE HAIR/OUTFITS):
   - Keep pointed ears and facial structure, but make the hair a tight short crop / tucked skull-cap (or high ponytail clear of the back) with NO long hair covering the neck, shoulders, or back bodice so the entire collar, shoulders, and upper back are 100% visible for 3D reconstruction.
2. STRICT SYMMETRICAL A-POSE (NO STICKY FEET):
   - Arms straight out at 45 degrees from the torso, open relaxed hands, clear white space between sleeves and waist.
   - Legs straight and separated shoulder-width apart with at least 40px of pure white space between the left and right thighs, calves, ankles, and boots in both Front and Back views (NO crossed legs, NO touching heels).
   - Keep any back dress/coat hem above mid-calf or split with a clear center gap so NO cloth bridges between the lower legs or touches the boots.
3. STUDIO BACKGROUND:
   - Pure flat #FFFFFF white background, zero ground shadow, zero floor line, zero UI borders or text.
```

### Gate 1 — Automated 2D Pre-Flight Check
Before spending Meshy AI credits, run:
```bash
python3 atelier/asset-forge/scripts/run_humanoid_character_pipeline.py --front /path/to/front.png
```
- **Pass criteria:** `boot_ankle_separated_row_fraction >= 0.75` and `min_center_gap_px >= 6` across the bottom `2%..22%` height band. If boots or skirt hems touch across the center line, the pipeline aborts immediately before calling Meshy AI.

## 3. Stage 2 — Meshy AI 3-Step Generation (`multi-image-to-3d` -> `remesh` -> `auto-rigging`)

Executed automatically by `atelier/asset-forge/scripts/run_humanoid_character_pipeline.py`:
1. **`POST /openapi/v1/multi-image-to-3d`**:
   - `ai_model: "meshy-5"`, `pose_mode: "t-pose"`, `topology: "quad"`, `target_polycount: 10000`, `should_remesh: true`, `should_texture: true`, `enable_pbr: false`.
2. **`POST /openapi/v1/remesh`**:
   - `topology: "triangle"`, `target_polycount: 5000`.
3. **`POST /openapi/v1/auto-rigging`**:
   - `height_meters: 1.65` (normalized to `0.94m` in Stage 3).

## 4. Stage 3 — Blender 4-Slot Modular Head & Hair Assembler (`modular_vroid_head.py`)

Implemented in [`atelier/asset-forge/scripts/modular_vroid_head.py`](file:///Users/pasitnusso/workspace/repos/atlas-world-svc/.claude/worktrees/F-188-interactive-playtest-sandbox-client-shar/atelier/asset-forge/scripts/modular_vroid_head.py) and wired into [`atelier/asset-forge/scripts/build_silme_seeress.py`](file:///Users/pasitnusso/workspace/repos/atlas-world-svc/.claude/worktrees/F-188-interactive-playtest-sandbox-client-shar/atelier/asset-forge/scripts/build_silme_seeress.py) and [`atelier/asset-forge/scripts/run_humanoid_character_pipeline.py`](file:///Users/pasitnusso/workspace/repos/atlas-world-svc/.claude/worktrees/F-188-interactive-playtest-sandbox-client-shar/atelier/asset-forge/scripts/run_humanoid_character_pipeline.py):

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python atelier/asset-forge/scripts/build_silme_seeress.py -- \
  --head-scale 1.0 \
  --ear-style elf \
  --hair-wave 1.0 \
  --vroid-hair /Users/pasitnusso/asset-studio-private/atlas-3d-plan/vroid_bases/Sendagaya_Shino.vrm
```

1. **Why We Never Carve a Partial `FaceMesh` into an AI 3D Head (`2-Part Head` Defect):**
   - In all VRoid `.vrm` models, `Face.baked` is only the front half of the face (`y = -0.111..+0.038`), while the **back skull + vertical neck cylinder (`SKIN`) + `HairBack` scalp cap** live inside `Body.baked`.
   - `modular_vroid_head.py` extracts `Body.baked[Neck + BackSkull]` (`z >= 1.432, |x| <= 0.105`) and welds its 46 boundary vertices directly into `Face.baked` (`< 0.1mm` tolerance, outer `skin_mat_idx` perimeter only so `EyeIris` / `FaceEyeline` / `FaceBrow` decal sheets and normals are never disturbed), producing ONE unified 360° `FaceMesh` that plugs into the AI body's neck collar (`collar_z = 0.764m`).
2. **Single Pointed Elf Ear Morph (`--ear-style elf`):**
   - Morphs VRoid's native ears (`|x| > 0.068`, `y > -0.006`, `z in 1.500..1.585`) outward into a single sleek pointed ear (`smoothstep(-0.006, 0.008, co.y)`), strictly excluding the temple/zygomatic arch in front of the ear (`y < -0.006`) so a second spike never forms.
3. **Clean Procedural Hair Strand Texture & Separate `CrownOrnamentMesh`:**
   - Builds a dedicated `VRoidHairStrandLuminance` vertical strand texture so `CharacterCustomization.ApplyHairColor()` tints `HairMesh` cleanly without dark UV blotches.
   - Separates the 3D gold ring & hairpin into `CrownOrnamentMesh` (`HairpinGold` material) so `CharacterCustomization.IsHairSurface` (which matches node names containing `"hair"`) never overwrites the metallic gold ornament with silver-white hair dye.
4. **Prevent "Sticky Feet" & T-Pose Export Bug:**
   - Any polygon below `z < 0.26m` bridging across `|x| < 0.014m` between left/right legs is removed and lower-leg weights are strictly partitioned (`x >= 0` -> `Left*`, `x < 0` -> `Right*`).
   - Always set `arm.data.pose_position = "POSE"` before `bpy.ops.export_scene.gltf(...)` so `build_mixamo_preset_pack.py` computes identity delta rotations (`R_Delta = I`).
