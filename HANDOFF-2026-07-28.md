- Models on `F:\comfy-ui`: **Z-Image Turbo** (winner), Animagine XL 4.0 + xinsir OpenPose ControlNet (tried, rejected — style regressed), Wan2.2 (video, untried).

**Winning recipe (v3):** Z-Image Turbo **img2img denoise 0.82 over flat-grey per-job silhouettes**
(cut from the approved human row via ImageMagick magenta-key). Proportion/pose comes from the
silhouette; race/costume from the prompt. Scripts in scratchpad: `zimage-charsheet.py` (txt2img),
`zimage-i2i.py` (img2img), `batch-race-jobs-v3.py` (full 8×8 matrix + muscle gradient).
Silhouettes already uploaded to `F:\comfy-ui\input\sil-<job>.png`.

Hard-won prompt laws:
- Text alone CANNOT hold head-body ratio — must anchor with an image (user caught drift twice).
- "raccoon"/"goggles"/"dwarf" drag the model to 3D-furry/Pixar; write "KEMONOMIMI, HUMAN face, no fur",
  "crisp flat 2D anime illustration, NOT 3D render NOT CGI NOT clay".
- Muscle gradient canon: race axis (Elf lightest → Ogre heaviest) × job axis (Mage → Swordsman), score 6.0→8.5.
- QC per-ROW on a contact sheet (`magick montage ... -tile 8x8`), then reroll only failing cells (new seed + reinforced identity words).

Race identity canon (locked by user iteration): Ogre = moss-green skin + small tusks + intelligent
eyes + natural muscle; Immortal halo = ring of LIGHT (not bells); Dragon = white hair + pearl-opal
iridescent skin; Beastkin = human face, animal ears/tail only (cat/dog/raccoon variants per job).
