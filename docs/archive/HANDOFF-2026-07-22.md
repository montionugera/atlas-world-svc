## Key gotchas / lessons

- **CI catches what local per-lane checks miss** — before promoting, run the CI
  trio locally in `colyseus-server`: `tsc --noEmit` (rootDir catches cross-dir
  test imports), `prettier --check "src/**/*.ts"`, full `jest`. Two real issues
  slipped to CI this session (a `scripts/` import outside `rootDir:src`, an
  unformatted file) and blocked the promote until fixed.
- **The R0 promote (`promote_release.py`) is blocked by the auto-mode classifier**
  from the agent Bash tool — the user runs it via the `!` prefix. `gh pr merge
  --squash` and `--cleanup-only` were NOT blocked.
- **`plan.md`** written by the claim skill at the worktree root: do NOT `git add`
  it (it collides add/add on merge into the release).
- **Fresh worktree setup:** `pnpm install` at root (npm fails on `workspace:*`),
  `npm install` in `scripts/` (js-yaml/ajv), and build `@atlas/contracts`
  (`cd contracts && npm run build`) before colyseus `tsc`.
