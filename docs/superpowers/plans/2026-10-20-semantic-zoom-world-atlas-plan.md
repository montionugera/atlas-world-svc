# Dedicated Semantic-Zoom World, Town & Multi-Floor Dungeon Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the World Studio Map into a dedicated, 100% data-driven Semantic-Zoom World, Town & Multi-Floor Dungeon Atlas Component (`DedicatedWorldAtlasComponent`) with uncluttered geographic travel paths, automatic 3-tier LOD zoom (`Macro Geography -> Regional Roads -> Town Street/Building/Marks + 1..12 NPC Roster`), clickable multi-floor Dungeon/Tower warp sub-maps (`B1⇄B2⇄B3`, `1F⇄2F⇄3F`), and real-time `Monster / Mini-Boss / Raid / MVP / Town Marks` filtering.

**Architecture:** Decouples declarative cartographic data in `content/studio/t_shaped_world_atlas.json` (validated by `content/studio/schemas/t-shaped-world-atlas.schema.json` and `scripts/studio_world_governance.py` `GOV-10`) from the UI state machine (`AtlasStateStore`, `OverlandGeographicRenderer`, and `DungeonSubMapRenderer`) inside `scripts/catalog_explorer_web.py`. High-resolution raster plates are deterministically generated via `scripts/generate_l2j_atlas_maps.py`.

**Tech Stack:** Python 3.13 (`http.server`, `unittest`, `Pillow`, stdlib recursive JSON Schema validator in `scripts/studio_world_governance.py` — no external `jsonschema` package required), Vanilla ES2022 + SVG/Canvas Cartography (`scripts/catalog_explorer_web.py`).
